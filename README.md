# 缠中说禅 · Chan Theory Skill

用**缠论**（缠中说禅理论）自动识别股票技术结构的 AI 技能包：自动算出**分型 → 笔 → 中枢 → 背驰 → 买卖点**，并出 K 线标注图。

支持 A 股 / 港股 / 美股。

```
输入: sh688411
输出: 9 笔 · 1 个中枢 · 1 处背驰 · 2 个买卖点  (+ 标注 K 线图)
```

---

## 这是什么

一个 **SKILL.md + Python 包**的混合技能：

- `SKILL.md` —— 给 AI 读的调用说明书（含大量踩坑记录，AI 照着做就不会错）
- `src/` —— 缠论计算内核，纯 Python 实现
- `tests/` —— 单元测试

换句话说：**它不是"让 AI 教你缠论"，而是"让 AI 调用一套跑通的缠论算法"。** AI 负责理解意图和解释结论，算法负责算数，两者不混在一起——这比让模型凭记忆口算分型可靠得多。

## ⚠️ 先读这一段：这不是严格的原典实现

用之前必须知道的边界，否则容易过度信任输出的买点：

| 事项 | 本实现的实际情况 |
|---|---|
| **级别** | 固定工作在**单一最低级别**，不实现原典的级别递归。中枢取的是「连续三笔的重叠区间」，而原典定义是「三个**次级别走势类型**重叠」——是**实用近似，不等价** |
| **背驰** | **不依托已成立的中枢**，只做相邻两笔的 MACD 面积比较。原典要求 a+A+b+B+c 五段结构、比较 a 与 c。中枢数为 0 时仍可能报背驰 |
| **走势类型** | **不做**趋势 / 盘整 / 未完成的分类，趋势背驰与盘整背驰被混同输出 |
| **异常 K 线** | **没有排除机制**。一字板、停牌、零成交段会原样进入计算，可能被误判为背驰（详见下） |
| **成交额** | 图上成交额**失真**，不可直接引用 |
| **数据新鲜度** | 返回值中**没有**滞后字段，调用方需自行确认最后一根 K 线日期 |

### 最需要警惕的坑：连续一字板

连续一字跌停期间成交量趋近 0，MACD 柱面积几乎归零，相对前期正常段呈现
教科书级的「力度衰减」形态 —— **可能被误判为底背驰**。
而一字板打开后第一根通常是**加速下跌**，不是反转。

> 标的近期有一字板或停牌时，该区间的背驰与买点结论一律视为「不可判定」。

## 三个必须知道的调用坑

**1. `days` 必须给 500，不要用默认 120。**
120 根 K 线通常只够识别出 2 笔，笔结构残缺，中枢和背驰全都识别不出来。实测同一只票：120 根 → 2 笔；500 根 → 9 笔 / 1 中枢 / 1 背驰。

**2. 不要手搓底层模块。**
直接调 `analyze_symbol()`。自己串底层模块如果漏掉 `simplify_klines`（缠论的「K 线包含关系合并」），会得出**完全相反**的结论——实测 124 个有效分型降到 55 个，9 笔变 10 笔，**1 个背驰凭空消失**，一类买点整个不见。

正确顺序：`route_kline → simplify_klines → identify_fenxing → identify_bis → identify_zhongshu → calculate_macd → detect_all_trend_beichis → identify_buy_sell_points`

**3. 数据默认前复权(qfq)。**
跨除权日的价格跳空会被误读为结构突破，同时污染笔端点、中枢上下沿与背驰比较基础。所选区间跨除权日时，结论可靠性下降。

## 输出纪律

使用本技能输出的结论**必须**带口径、失效条件和置信度，不能只给一个买卖点：

```
[数据口径] 源=<...> 复权=<qfq> 
[数据新鲜度] 最后K线=<日期> 
[结构]     笔=<N> 中枢=<N>
[背驰]     <背驰/不背驰/无> 力度对比=<第A笔 vs 第C笔>
[信号]     <第N类买点/第N类卖点/无>
[触发价]   <价格>   ← 结构触发位，不是预测价
[失效条件] <跌破/站上 X 则作废> 锚定=<笔端点或中枢边界>
[置信]     <高/中/低> 最弱的一环=<...>
```

规则：**每个数字要么写计算值并注明口径，要么写「不可得(原因)」** —— 不许留空、不许"约""大约"。

**「触发价」是结构位不是预测价**，**缠论的「走势终完美」是对已发生走势的分类学描述，对未发生路径不具预测力**，禁止转写成「接下来会到 X」。

## 已知限制

- **图上的成交额失真**：akshare 在科创板上 `Volume` 恒为 0，`Amount` 同样失真（实测图上峰值 0.15 亿，真实约 40.5 亿，低估 270 倍）。要做量能分析请改用东方财富 `push2his` 的 `f57` 字段。
- 内置图表**不画中枢**（`zg`/`zd` 完全不出现），也只画最近 5 个分型标记，不画完整笔连线。要完整结构图请自行用 matplotlib 重绘。
- 纯技术分析，**不接基本面**。
- 不构成投资建议。
